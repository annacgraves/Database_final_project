This project is a simple and personal Spotify listening dashboard. 
As of right now, this is based on my very own listening data (because it takes up to 30 days to retrieve data from Spotify).

Users who implement this application will have a database created, as well as a dashboard that displays stats such as listening pie charts, top artist, top song, and most globally popular artists.
There will also be a modifiable profile where users can enter their mood/genre of the moment and get song recommendations. It also lets users search and save their favorite songs from their listening.
